# Android 时光机（MyLife Timeline）首页设计

> 本文只描述时光机首页（入口、浏览、搜索、范围与页面状态）的功能与高层设计。
> 图片画廊、热点时段、语音画廊、事件列表等子页面，以及数据生产、BFF 与检索后端不在本文范围，边界见 §9。
> 内容以当前 Android 代码为准，不涉及具体实现细节。

## 1. 定位

时光机是 MyLife 在 Android 上的首页与唯一入口，用**时间范围摘要**回看个人生活记录：

- 以「日 / 周 / 月 / 年」四种粒度浏览，默认「日」；
- 卡片只呈现摘要信息：范围标题、活跃时段、摘要、关键帧缩略图、主题；
- 支持全局搜索，搜索结果以事件命中列表呈现；
- 从摘要下钻或进入子页面查看更细的内容；
- 分析中的记录在页面上以「分析中…」状态呈现；近期记录在完成后会自动更新（轮询范围见 §6.3）。

设计原则：

| 原则 | 含义 |
|---|---|
| 摘要优先 | 首页不铺原始事件流；一屏是若干周期的摘要卡片 |
| 新到旧 | 周期卡片与分组头均按时间倒序，最新在最上 |
| 本地聚合 | 周/月/年卡片由已加载的日级摘要确定性聚合，不额外请求摘要、不调用 LLM |
| 分层下钻 | 月卡 → 日粒度并只显示该月；年卡 → 月粒度并只显示该年 |
| 搜索全局 | 搜索不受当前粒度或下钻范围影响 |
| 状态可见 | 加载、空、错误、分析中、加载更早都有明确反馈 |

## 2. 入口与页面骨架

### 2.1 入口

- 会话页右上角更多菜单中的「时光机」进入；
- 路由无参数，不提供日期/会话深链；
- 页面为单视图：无底部 tab、无底栏；左上返回回到会话页。

### 2.2 页面框架

```
┌──────────────────────────────────────┐
│ ←  时光机                            │  宿主头部（返回 + 标题）
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ 搜索…                      清除  │ │  常驻搜索框
│ └──────────────────────────────────┘ │
│                                      │
│  [ 日 | 周 | 月 | 年 ]                │  粒度选择器（仅浏览模式）
│                                      │
│  2026年 · 8月                        │  分组头
│  ┌────────────────────────────────┐  │
│  │ 8月21日 · 周四                 │  │  周期卡片
│  │ 分析中…                        │  │
│  │ ▸ 09:12   ▸ 14:00     语音 3   │  │  活跃时段 / 语音入口
│  │ 摘要行…                        │  │
│  │ [缩略图] [缩略图] [缩略图]       │  │  关键帧
│  │ [主题] [主题]                   │  │  主题 chip
│  └────────────────────────────────┘  │
│  …                                   │
│              加载更早                 │  列表 footer
│                                      │
│             只看 2026年8月 ✕          │  下钻范围 pill（有 scope 时）
└──────────────────────────────────────┘
```

- 背景为 MyLife 独立视觉：深色底、静态星点、金色标题/分组头、半透明面板卡片；
- 搜索框在两种模式下都常驻；
- 粒度选择器只在浏览模式出现；搜索模式用搜索结果整体替换「选择器 + 列表」区域；
- 有下钻范围时，底部居中显示范围 pill，覆盖在列表之上。

## 3. 浏览模式

### 3.1 粒度模型

| 粒度 | 卡片表达 | 分组头 | 卡片本体点击 | 典型入口 |
|---|---|---|---|---|
| 日 | 单日摘要 | 该日所在月 | 不可点 | 默认粒度 |
| 周 | ISO 周（周一至周日）摘要，标题含周序号 | 周一所在月 | 不可点 | 选择器 |
| 月 | 整月摘要 | 该月所在年 | 下钻到该月的日粒度 | 选择器 |
| 年 | 整年摘要 | 无，平铺 | 下钻到该年的月粒度 | 选择器 |

- 选择器为四选一的分段控件，选中项以金色勾选标识；
- 切换粒度立即在本地重聚合，不跳转、不重置已加载窗口；
- 手动切换粒度会清除当前下钻范围；
- 从较浅的浏览窗口切到月/年时，如果当前窗口不足以覆盖一个聚合单位且还有更早数据，会补取一页后继续聚合；补页失败不打断已有内容的展示。

### 3.2 分组头

| 粒度 | 分组头规则 |
|---|---|
| 日 | 按日期的年月分组（如「2026年 · 8月」） |
| 周 | 按 ISO 周**周一所在月**分组；跨月周只出现一次 |
| 月 | 按年份分组（如「2026年」） |
| 年 | 无分组头，直接平铺 |

分组头使用大号金色文字；月分组头为「年 · 月」，年分组头为「年」。

### 3.3 周期卡片

四种粒度共用同一套信息结构，自上而下：

| 区块 | 内容与规则 |
|---|---|
| 分析状态 | 组内任一天仍在分析时，顶部显示脉冲点 +「分析中…」 |
| 标题行 | 范围标签；日卡带星期，周卡带本地化周序号（如「33周」），月/年卡为月/年标签 |
| 活跃时段 | 仅日卡；服务端给出的至多 3 个活跃时段，每个 chip 只显示开始时间（如「09:12」），点击进入热点时段查看器 |
| 语音入口 | 仅日卡且当日有语音段时出现；显示语音图标与段数，与活跃时段同一行靠右；无活跃时段时单独成行 |
| 摘要 | 日卡展示全部摘要；周/月/年卡默认最多 4/5/6 条摘要，每条折叠为 2 行，超出显示「+N 条」可展开；周/月/年卡组内没有任何摘要时降级为「范围 + 天数」行（如「2026年8月共 31 天」） |
| 关键帧 | 3 列正方形缩略图；日/周/月/年最多 3/9/12/15 张；真实关键帧数多于展示数时，首行末图右上角显示总数角标；点击任一缩略图或角标进入图片画廊 |
| 主题 | 自动换行的描边 chip；日卡展示全部主题，周/月/年卡聚焦高权重主题（上限 50）；点击主题进入全局搜索 |

补充规则：

- 缩略图从周期内的关键帧中按时间窗轮转挑选，避免单一时间段占满图片区；
- 卡片不展示原始事件计数或统计徽章；图片总数角标和语音段数是仅有的事件计数信息；
- 日卡/周卡本体不可点；月卡/年卡点击卡片空白区域下钻，卡片内部的时段、语音、图片、主题各自消费点击，不触发下钻；
- 「分析中」也适用于聚合卡：周期内任意一天未完成分析即显示，聚合在数据更新后自动重算。

### 3.4 下钻与范围（Scope）

- 月卡 → 粒度切到「日」，列表只显示该月的日卡；
- 年卡 → 粒度切到「月」，列表只显示该年的月卡；
- 下钻不产生新的导航路由，只是页面内的粒度 + 范围状态；
- 下钻数据来自已加载窗口，进入时即可完整展示该范围（能被点击的月/年卡必是已闭合周期）；
- 下钻后底部显示范围 pill（如「只看 2026年8月 ✕」），点击 pill 升级为清除范围，保持当前粒度并恢复全量；
- 手动切换任意粒度也会清除范围；
- 下钻范围内不显示分页 footer，也不触发触底加载；
- 设备时区变化导致日界重排时，自动退出下钻范围；
- 范围内无数据时，空态文案带范围（如「2026年8月没有记录」）。

### 3.5 列表顺序、分页与滚动

- 卡片与分组头均按时间倒序；
- 浏览数据按「天」分页，页面只保留已加载窗口；首屏与日/周粒度按 30 天加载，月粒度 90 天，年粒度 366 天；
- 列表接近底部（距末尾约 3 个条目）时自动加载更早一页；每次自动触发必须带来列表条目增长，避免无新内容时反复翻页；
- 列表 footer 提供明确状态：
  - 「加载更早」：可点击加载；
  - 「加载更早的记录…」：加载中；
  - 「加载失败，点击重试」：失败后暂停自动加载，点击 footer 重试；
  - 「已到最早」：没有更多；
- 分页窗口最旧的**未闭合周期**不作为卡片展示，由 footer 承载"继续加载"；否则会出现半截的月/年卡；
- 下钻范围内不出现 footer，也没有触底加载；
- 滚动位置规则：
  - 从图片画廊、热点时段、语音画廊、事件列表返回时，保持原列表位置（浏览或搜索各用各的位置）；
  - 真正切换粒度或下钻时才回到列表顶部；
  - 浏览与搜索使用各自独立的滚动位置，互不覆盖。

## 4. 搜索模式

### 4.1 触发与输入

- 搜索框常驻页面顶部；
- query 非空即进入搜索模式，搜索结果替换浏览列表，粒度选择器隐藏；
- 最少 2 个字符才发起搜索；不足 2 个字符时显示「至少输入 2 个字」，不发请求；
- 输入有 350ms 防抖；键盘搜索键立即发起当前查询；
- 清除按钮、清空文本、系统返回键都会清空 query 并退出搜索模式；
  - 返回键在搜索模式下只消费一次，用于清空 query，不退出时光机路由；
- 点击搜索框外部仅收起键盘、清除焦点，不清空 query。

### 4.2 结果列表

```
共 N 条结果
日期 A
  [类型] 10:24  命中摘要…（最多两行，命中词高亮）
  [类型] 09:12  命中摘要…
日期 B
  [类型] 18:40  命中摘要…
```

> 上例只示意分组结构，不代表日期排序。

- 结果按命中首次出现的日期分组；组间顺序由检索结果顺序决定，组内保持相关度顺序；日期头使用本地化的月/日（当前不含年份）；
- 顶部显示结果总数；
- 行内包含类型标识、本地时间、最多两行的片段；命中词在片段中首次出现处以金色高亮（不区分大小写）；
- 类型集合为五类可展示事件：

| 类型 | 说明 |
|---|---|
| 对话 | chat |
| 转录 | transcribe |
| 翻译 | translate |
| Agent 任务 | agent_job |
| 画面 | video 关键帧 |

- 点击任一条命中进入事件列表查看器，定位到命中时刻，并透传命中日的分析中状态（以当前已加载窗口中的该日为准；未加载则视为无）；没有命中时刻的条目不响应；
- 列表触底自动续页，使用游标继续加载；续页失败保持已有结果，不切换为错误页；
- 搜索结果不做缓存，每次查询直通检索接口。

### 4.3 与浏览状态的关系

- 搜索是全局的，不受当前粒度或下钻范围过滤；
- 若存在下钻范围，范围 pill 仍显示在底部，可随时清除；搜索本身不使用该范围；
- 退出搜索后回到浏览列表，保留进入搜索前的浏览粒度、范围与滚动位置；
- 从搜索结果进入子页面再返回时，搜索 query 与结果状态保留，滚动位置保持。

## 5. 状态与反馈

| 场景 | 页面表现 |
|---|---|
| 首屏数据未就绪 | 列表区域显示加载提示；若共享窗口已有缓存则直接渲染缓存 |
| 浏览加载失败 | 列表区域错误提示 + 重试按钮 |
| 无任何记录 | 空态：「还没有记录，开始一次对话吧」 |
| 下钻范围无记录 | 空态：「{范围}没有记录」 |
| 当前窗口无可见卡片但仍有更早数据 | 不显示空态，显示 footer 以继续加载更早 |
| 触底加载中 / 失败 / 到头 | footer 四态（见 §3.5） |
| 周期内存在分析中的天 | 卡片顶部「分析中…」脉冲点 |
| 搜索不足 2 字符 | 提示「至少输入 2 个字」 |
| 搜索请求中 | 「搜索中…」 |
| 搜索无结果 | 「没有找到相关结果」 |
| 搜索首屏失败 | 搜索区域错误提示 + 重试 |
| 搜索续页失败 | 保留已有结果，不切错误页 |
| 分析轮询失败 | 保留当前内容，下个轮询周期重试，不打断浏览 |

## 6. 数据与刷新

### 6.1 数据来源

首页的业务数据只来自两类接口：

| 用途 | 接口 | 关键数据 |
|---|---|---|
| 浏览 | `GET /api/mylife/overview` | 设备时区、每日摘要、主题、活跃时段、关键帧、分析状态、分页游标 |
| 搜索 | `GET /api/mylife/search` | 命中总数、命中片段、类型、日期/时刻、分页游标 |

- 浏览接口按天返回当前时区下的日级摘要窗口；请求携带设备当前时区与分页参数，响应带服务端实际时区、已加载天、下一页游标；
- 首页不直接调用 `/timeline`；该接口只服务于子页面（图片/热点时段/语音/事件列表）；
- 缩略图在数据出口已转换为可直接加载的绝对媒体地址。

### 6.2 窗口与合并

- 首页使用一个「已加载窗口」（由共享数据层维护），而不是一次性全量；
- 新页按日期去重合并进窗口，已加载的更深数据不会被浅页覆盖；
- 每次进入时光机路由（新页面实例）强制拉取第一页，即使内存中已有旧快照，避免展示分析完成前的旧摘要；从子页面返回时页面状态保留；
- 响应时区与当前窗口不一致时，丢弃旧窗口并按新时区重建；下钻范围同时清除；
- 浏览窗口只保存在进程内共享缓存中，不做本地持久化；进程重启后重新拉取。

### 6.3 分析中与自动更新

- 轮询范围为已加载窗口中最新的至多 400 天；范围内只要有任一天处于分析中，共享数据层每 60 秒重取一次该范围；没有分析中的天时停止轮询；
- 更早的深尾不参与自动轮询；
- 轮询与页面生命周期解耦：分析完成后的数据会推送到页面，卡片自动重聚合，无需用户手动刷新；
- 轮询失败不改变当前展示，按周期重试。

### 6.4 刷新策略

页面**没有下拉刷新手势**。内容更新由以下行为驱动：

1. 进入时光机路由（新页面实例）时强制拉取第一页；
2. 分析中的 60 秒轮询；
3. 列表触底加载更早一页；
4. 浏览/搜索错误态的重试；
5. 子页面产生的数据变更及其刷新机制由对应子页面设计负责（不在本文范围）；首页通过共享窗口自动接收更新。

## 7. 导航与页面状态

| 触发 | 去向 | 携带信息 |
|---|---|---|
| 会话页菜单「时光机」 | 时光机首页 | 无（路由无参数） |
| 左上返回 | 返回会话页 | — |
| 系统返回键（query 为空） | 返回会话页 | — |
| 月卡空白区域 | 页内：日粒度 + 该月范围 | 月 key |
| 年卡空白区域 | 页内：月粒度 + 该年范围 | 年 key |
| 卡片图片 / 数量角标 | 图片画廊 | 日期范围、展示标签、被点帧、分析中状态 |
| 日卡活跃时段 chip | 热点时段查看器 | 时段起止时刻、分析中状态 |
| 日卡语音入口 | 语音画廊 | 日期、展示标签、段数、分析中状态 |
| 主题 chip | 页内搜索模式 | 主题搜索词 |
| 搜索命中行 | 事件列表查看器 | 命中时刻、命中日分析中状态 |
| 搜索模式系统返回 | 退出搜索 | 清空 query |

- 子页面以独立路由压栈；首页保留在返回栈中，因此从子页面返回时保持粒度、范围、query 与滚动位置；
- 离开时光机（返回会话页）后页面状态随路由销毁；再次进入回到默认日粒度、无范围、空 query，并重新拉取首屏；
- 进程重建后粒度、范围、搜索 query 回到默认状态，数据重新拉取；
- 所有子页面共享首页传入的「分析中」状态，用于其自身的顶栏提示（具体展示由子页面设计决定）。

## 8. 视觉、时区与本地化

- **视觉空间**：时光机使用 MyLife 独立子主题——深色底、静态星点背景、金色标题与分组头、灰蓝色次要文字、半透明面板、12dp 圆角卡片、8dp 圆角缩略图；
- **卡片密度**：图片固定 3 列方格；主题与活跃时段 chip 自动换行，适配窄屏和字体放大；
- **时区**：以设备当前时区划分「日」，请求随带时区；时区变化会重建窗口并退出下钻；搜索命中时间按设备本地时间显示；
- **本地化**：日期/周/月/年标签、周序号、搜索占位与全部状态文案均随 UI locale 本地化；卡片日期标签、周范围标签、活跃时段与搜索结果时间在阿拉伯语下使用本地数字形式；天数、结果数、语音段数使用复数规则；
- **可访问性**：语音入口合并为单个可读元素（如「语音记录，N 段」）；列表 footer、主题 chip、时段 chip 均为可读文本。

## 9. 边界与非目标
