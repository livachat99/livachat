## 1. 产品概述

### 1.1 一句话描述
一个能"看见"你、记住你、和你一起成长的 AI 伙伴和助手.

### 1.2 核心价值
- **低延迟**：端到端延迟 < 1s
- **高自然度**：自然语音交互，支持打断
- **多模态**：语音 + 视频理解
- **有记忆**：长期记忆用户偏好和上下文，和用户一起成长
- **原生体验**：iOS/Android 原生开发，极致性能

### 1.3 目标用户

| 用户类型 | 核心场景 | 痛点 | 价值主张 |
|---------|---------|------|---------|
| 孤独/社交焦虑者 | 深夜陪伴、倾诉 | 无人倾听、社交压力 | 随时在线、无评判的倾听者 |
| 语言学习者 | 口语练习、纠错 | 找不到语伴、怕犯错 | 耐心的 AI 语伴，实时纠错 |
| 日常记录者 | 记录日常所看，所听 | 自动记录和总结 | AI分析总结，碎片生活的数据价值 |

#### WebSocket 协议设计

基本格式使用JSON RPC. 

```typescript
// 连接建立
wss://api.example.com/v1/stream?token={jwt}&user_id={uuid}

// 客户端 → 服务端
interface ClientMessage {
  type: 'audio' | 'video' | 'interrupt' | 'ping' | 'pong';
  seq: number;           // 序列号，用于丢包检测
  timestamp: number;     // 客户端发送时间戳
  payload: {
    // type: 'audio' - Base64 encoded Opus chunk (20-40ms)
    audio?: string;
    
    // type: 'video' - Base64 encoded JPEG image
    video?: string;
    frame_id?: number;   // 视频帧序号
    
    // type: 'interrupt' - 打断当前 AI 说话
    reason?: 'user_voice' | 'manual';
  };
}

// 服务端 → 客户端
interface ServerMessage {
  type: 'transcription' | 'ai_text' | 'ai_audio' | 'ai_video_ack' | 'status' | 'error';
  seq?: number;
  timestamp: number;
  payload: {
    // type: 'transcription' - ASR 结果
    text?: string;
    is_final?: boolean;    // 是否最终识别结果
    
    // type: 'ai_text' - AI 文本回复（流式）
    text?: string;
    message_id?: string;
    
    // type: 'ai_audio' - TTS 音频流
    audio?: string;        // Base64 Opus chunk
    is_final?: boolean;    // 是否最后一段音频
    
    // type: 'ai_video_ack' - 视频帧确认
    frame_id?: number;
    processed?: boolean;   // 是否已处理
    
    // type: 'status' - 状态更新
    status?: 'connecting' | 'listening' | 'thinking' | 'speaking' | 'idle' | 'error';
    
    // type: 'error'
    error_code?: string;
    error_msg?: string;
  };
}
```

```

    ▼

    ▼

    ▼

    │
    ▼

```

### 2.3 Phase 3: WebRTC 实时音视频（产品 2.0）

**目标**：极致低延迟体验，专业级实时通信  
**时间**：产品 2.0 阶段（P1/P2 验证 PMF 后）  
**技术方案**：WebRTC + SFU

#### 适用场景

- 用户规模达到 10万+ DAU
- 对延迟要求极高的场景（如远程协作、实时翻译）
- 需要 P2P 或低服务器成本时

#### WebRTC vs WebSocket 对比

| 维度 | WebSocket (P1) | WebRTC (2.0) |
|------|----------------|--------------|
| 延迟 | 200-500ms | < 100ms |
| 音频质量 | 依赖编码/网络 | 自适应码率、FEC |
| 服务器成本 | 高（流量中转） | 低（P2P 或 SFU）|
| 开发复杂度 | 低 | 高 |
| 视频支持 | 1fps JPEG | 30fps 原生 |
| 适用阶段 | MVP 验证 | 规模化阶段 |
