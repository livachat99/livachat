## 1. 用户故事 (User Stories)

### P0 核心需求

| 编号 | 用户故事 | 优先级 |
|------|----------|--------|
| US-01 | 作为一个**孤独/社交焦虑者**，我想要**随时打开App就能和AI对话**，以便于**在深夜或独处时获得陪伴，无需担心被评判** | P0 |
| US-02 | 作为一个**语言学习者**，我想要**用语音和AI进行自然对话练习**，以便于**提升口语流利度，获得实时发音和语法纠正** | P0 |
| US-03 | 作为一个**用户**，我想要**说话时AI能立即停下并听我说**，以便于**自然地打断和纠正对话，就像和真人聊天一样** | P0 |
| US-04 | 作为一个**日常记录者**，我想要**让AI看到我所处的环境**，以便于**分享当下的心情和场景，获得更有针对性的回应** | P0 |
| US-05 | 作为一个**用户**，我想要**清楚知道AI当前是在听、在想还是在说**，以便于**掌握对话节奏，知道何时可以发言** | P0 |
| US-06 | 作为一个**用户**，我想要**在网络不稳定时对话能自动恢复**，以便于**不因技术问题而中断情感交流** | P0 |

## 3. 交互状态定义

### 3.1 全局状态指示器

| 状态 | 视觉表现 | 文案提示 | 用户可操作 |
|------|----------|----------|------------|
| **离线** | 灰色圆点 | "离线中" | 检查网络设置 |
| **连接中** | 黄色脉冲动画 | "正在连接..." | 等待或取消 |
| **在线-待机** | 绿色呼吸灯 | "随时可以说" | 点击麦克风/直接说话 |
| **聆听中** | 蓝色波形动画 | "我在听..." | 继续说话 |
| **思考中** | 黄色旋转图标 | "让我想想..." | 可打断 |
| **说话中** | 绿色音波动画 | "正在说..." | 可打断 |

### 3.2 页面状态定义

#### 主对话页

| 状态 | 视觉表现 | 交互反馈 |
|------|----------|----------|
| **默认态** | AI头像静态，麦克风按钮可点击 | 背景为柔和渐变色 |
| **空数据态** | 首次使用显示欢迎语 | "嗨，我是你的AI伙伴，随时找我聊天吧" |
| **加载态** | 连接中显示脉冲动画 | "正在唤醒你的伙伴..." |
| **成功态** | 连接成功，AI主动问候 | 播放问候语音，头像微动 |
| **失败态** | 连接失败显示重试按钮 | "连接不太顺畅，再试一次？" |

#### 历史记录页

| 状态 | 视觉表现 | 交互反馈 |
|------|----------|----------|
| **默认态** | 按时间倒序排列对话卡片 | 左滑删除，点击进入详情 |
| **空数据态** | 显示插画+文案 | "还没有对话记录，开始第一次聊天吧" |
| **加载态** | 骨架屏加载 | 渐进式加载动画 |

#### 设置页

| 状态 | 视觉表现 | 交互反馈 |
|------|----------|----------|
| **默认态** | 分类列表展示 | 开关、选择器、滑块 |
| **成功态** | Toast提示 | "设置已保存" |

## 6. 手势与动效

### 6.1 手势操作

| 手势 | 触发区域 | 操作 |
|------|----------|------|
| **捏合** | 视频预览 | 放大/缩小 |
| **左滑** | 历史记录项 | 删除对话 |


### 6.2 状态切换动画

#### 连接流程动画

```
IDLE → CONNECTING:
- AI头像: 从静态变为脉冲呼吸效果 (0.3s ease)
- 状态文案: 淡入"正在连接..." (0.2s)
- 背景: 轻微变暗 (0.3s)

CONNECTING → LISTENING:
- AI头像: 状态环变为蓝色，开始波形动画 (0.3s spring)
- 状态文案: 淡入"我在听..." (0.2s)
```

#### 对话状态流转动画

```
LISTENING → THINKING:
- AI头像: 波形停止，显示旋转思考图标 (0.3s)
- 状态环: 蓝色 → 黄色 (0.2s)

THINKING → SPEAKING:
- AI头像: 开始说话动画 (缩放+波形) (0.3s spring)
- 状态环: 黄色 → 绿色 (0.2s)
- 消息气泡: 从底部滑入 (0.4s ease-out)
- 触觉反馈: 轻微震动

SPEAKING → LISTENING (打断):
- AI头像: 立即停止说话动画 (0.1s)
- 当前消息: 保持显示，新消息从下方准备 (0.2s)
- 状态环: 绿色 → 蓝色 (0.2s)
```

### 6.4 打断机制动效

```
用户说话打断AI:
```
