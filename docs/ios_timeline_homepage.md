# iOS 时光机首页设计

**状态**：已实现（2026-10-22）
**UI/UX 基线**：`docs/android_timeline_homepage.md` 与 Android 现行代码（`TimelineScreen.kt`、`TimelineViewModel.kt`、`PeriodAggregator.kt`、`PeriodCard.kt` 等）。
**共享基础**：`docs/ios_timeline_arch.md`（网络、Store、导航、主题、本地化、测试）。
**范围**：入口、首页骨架、粒度浏览、周期卡片、下钻、分页、搜索模式 UI、页面状态、导航到子页的参数。
**不在范围**：搜索/Topic 的数据细节（`ios_timeline_topics.md`）、热点时段（`ios_timeline_hotslot.md`）、图片画廊（`ios_timeline_image_gallery.md`）、语音画廊（`ios_timeline_audio_gallery.md`）、后端数据生产。

---

## 1. 定位

时光机用**时间范围摘要**回看个人生活记录：

- 以「日 / 周 / 月 / 年」四种粒度浏览，默认「日」；
- 卡片只呈现摘要：范围标题、活跃时段、摘要、缩略图、主题、语音入口；
- 全局搜索，结果以事件命中列表呈现；
- 从摘要下钻或进入子页看更细内容；
- 分析中的记录显示「分析中…」，近期记录完成后自动更新（Store 60s 轮询）。

设计原则（与 Android 一致）：

| 原则 | 含义 |
|---|---|
| 摘要优先 | 首页不铺原始事件流 |
| 新到旧 | 周期卡与分组头均时间倒序 |
| 本地聚合 | 周/月/年卡片由已加载日摘要确定性聚合，不额外请求、不调用 LLM |
| 分层下钻 | 月卡 → 日粒度并只看该月；年卡 → 月粒度并只看该年 |
| 搜索全局 | 不受当前粒度或下钻范围过滤 |
| 状态可见 | 加载、空、错误、分析中、加载更早均有明确反馈 |

## 2. 入口与页面骨架

### 2.1 入口

- 会话页右上「⋯」菜单 →「时光机」；
- 无参数、无深链、无日期定位；
- 单视图页面：无底部 tab、无底栏；
- 打开不停止实时会话；关闭回到会话页。

### 2.2 骨架

```
┌──────────────────────────────────────────┐
│ ←  时光机                                │  宿主顶栏（52pt）
│                                          │
│ ┌──────────────────────────────────────┐ │
│ │ 🔍 搜索…                         ✕  │ │  常驻搜索框
│ └──────────────────────────────────────┘ │
│                                          │
│  [✓ 日 | 周 | 月 | 年]                   │  粒度选择器（仅浏览模式）
│                                          │
│  2026年 · 8月                            │  分组头
│  ┌────────────────────────────────────┐  │
│  │ 8月21日 · 周四                     │  │  周期卡
│  │ ● 分析中…                          │  │
│  │ ▸ 09:12  ▸ 14:00          ◉ 3     │  │  活跃时段 / 语音入口
│  │ 摘要…                              │  │
│  │ [图] [图] [图]              [12]   │  │  关键帧 + 总数角标
│  │ [主题] [主题]                      │  │  主题 chip
```

- 背景：Abyss + 静态星点；面板卡片半透明 Panel；
- 搜索框两种模式都常驻；
- 粒度选择器仅浏览模式出现；
- 有下钻范围时底部居中显示范围 pill，覆盖在列表之上。

## 3. 浏览模式

### 3.1 粒度模型

| 粒度 | 卡片表达 | 分组头 | 卡片本体点击 | 入口 |
|---|---|---|---|---|
| 日 | 单日摘要 | 该日所在月 | 不可点 | 默认 |
| 周 | ISO 周（周一至周日）摘要，标题含周序号 | 周一所在月 | 不可点 | 选择器 |
| 月 | 整月摘要 | 该月所在年 | 下钻到该月的日粒度 | 选择器 |
| 年 | 整年摘要 | 无，平铺 | 下钻到该年的月粒度 | 选择器 |

- 选择器为四选一分段控件（外形按 M3 `SegmentedButton`：整体圆角、分段相连）；高度约 40；选中项以 18pt 金色对勾标识，未选为 Dust；两者容器底色一致（Panel 60%），不做填充高亮。
- 切换粒度立即在本地重聚合，不跳转、不清空已加载窗口；
- 手动切换粒度清除当前下钻范围；
- 从较浅窗口切到月/年时，若已加载天数 < 该粒度页大小且仍有更早数据，补取一页后继续聚合；补页失败不打断已有内容。

### 3.2 分组头

| 粒度 | 规则 |
|---|---|
| 日 | 按日期年月分组（`2026年 · 8月` / `Aug 2026`） |
| 周 | 按 ISO 周**周一所在月**分组；跨月周只出现一次 |
| 月 | 按年份分组（`2026年` / `2026`） |
| 年 | 无分组头，直接平铺 |

样式：28/36 regular，Gold 70%，水平 16 / 垂直 8。月分组头使用 `mylife_overview_month`；年分组头使用年标签。分组头是列表 item，使用稳定 key（`header-<key>`）。

### 3.3 周期卡片

四种粒度共用同一信息结构，自上而下：

| 区块 | 内容与规则 |
|---|---|
| 分析状态 | 组内任一天 `has_pending == true`：8pt Gold 脉冲点 +「分析中…」（14/20 Dust）；下方 8pt 间距 |
| 标题行 | 范围标签；日卡带星期；周卡范围 = 组内最新一天所在 ISO 周的周一至周日，并在标签右侧 8pt 处加周序号（`W33` / `33周`，12/16 Dust）；月/年卡为月/年标签。16/24 medium Star |
| 活跃时段 | 仅日卡；至多 3 个 chip，只显示开始时间（`▸ 09:12`）；点击进入 hotSlotView |
| 语音入口 | 仅日卡且 `audioCount > 0`；与活跃时段同一行靠右；无活跃时段时单独成行 |
| 摘要 | 日卡展示全部摘要且不可折叠；周/月/年卡默认最多 4/5/6 条，每条折叠为 2 行；超出显示「+N 条」可展开，展开后点击摘要行可收起。周/月/年组内没有任何摘要时降级为「范围 + 天数」（如 `2026年8月共 31 天` / `Aug 2026 · 31 days`）；天数 = 组内 overview 日卡数，无事件的日不落行，不等于日历总天数 |
| 关键帧 | 3 列正方形缩略图；日/周/月/年最多 3/9/12/15 张；真实关键帧数多于展示数时，首行末图右上角显示总数角标；点击任一缩略图或角标进入 Gallery |
| 主题 | 自动换行的描边 chip；日卡展示全部主题；周/月/年卡按权重聚焦（上限 50）；点击进入全局搜索 |

补充规则：

- 缩略图按时间窗轮转选取，避免单一时间段占满图片区；
- 除图片总数角标与语音段数外，不展示原始事件计数/统计徽章；
- 日卡/周卡本体不可点；月/年卡点击卡片空白区域下钻；卡片内部时段、语音、图片、主题各自消费点击，不触发下钻；
- 无摘要降级行的本地方案：en 按复数 `1 day` / `N days`（`Aug 2026 · 1 day`）；zh 恒为 `{范围}共 N 天`；
- 「分析中」也适用于聚合卡：组内任意一天未完成即显示；
- 聚合在 Store 窗口更新后自动重算。

#### 3.3.1 卡片视觉

- 卡片：Panel 60%，圆角 12，水平外边距 16 / 垂直 4，内边距 16。
- 卡片 key：`period-<digest.key>`。
- 图片网格：按 3 张一行组织；**行内图片等分该行宽度**（对齐 Android `Row + weight(1f)`）：满行 3 张各 1/3，最后一行不足 3 张时拉伸等分（1 张占满整行、2 张各 1/2）；每张 1:1，`scaledToFill`，圆角 8，间距 4；占位/失败 Panel；加载完成前也占位。不要用固定 3 列 `LazyVGrid`（会在末行留空，与 Android 不一致）。
- 计数角标：`imageTotal > images.count` 时显示；胶囊黑 60%，Star `labelSmall`，水平 6 / 垂直 1；相对首行末图右上角偏移 (+10, −10)；显示角标时图片区上方额外补 10pt；角标整体可点。
- 主题 chip：透明底 + 1pt Line 描边 + Dust `labelMedium`；水平 8 / 垂直 2；胶囊；可点与纯展示同款视觉。
- 活跃时段 chip：Panel 80% 胶囊 + Gold `labelMedium`；水平 8 / 垂直 2；标签 `▸ HH:mm`。
- 语音入口：Panel 80% 圆形图标底 + Gold 波形图标（18pt）+ Dust 段数（12/16）；整行可点。
- 用户/AI 气泡色不在此页出现；本页只用 MyLife 色板。

### 3.4 下钻与范围（Scope）

- 月卡 → 粒度切到「日」，只显示该月的日卡；
- 年卡 → 粒度切到「月」，只显示该年的月卡；
- 下钻不产生新路由，只是页内「粒度 + scopeKey」；
- 下钻数据来自已加载窗口；可点的月/年卡必是已闭合周期；
- 下钻后底部显示范围 pill（`只看 2026年8月 ✕` / `Aug 2026 only ✕`）；Gold 90% 胶囊、Abyss 文字（12/16 medium）、水平 16 / 垂直 8，底部距安全区 16；
- 点击 pill 清除范围，保持当前粒度并恢复全量；
- 手动切换任意粒度也清除范围；
- 下钻范围内不显示 footer，不触发触底加载；
- 设备时区/响应时区变化导致日界重排时，自动退出下钻；
- 范围内无数据：空态文案带范围（`2026年8月没有记录` / `No records in Aug 2026`）。

### 3.5 列表顺序、分页与滚动

- 卡片与分组头均按时间倒序，最新在最上；列表使用 `ScrollView + LazyVStack`，分组头/卡片使用稳定 key。
- 浏览数据按「天」分页；页大小：
  - 首屏、日/周粒度：30 天
  - 月粒度：90 天
  - 年粒度：366 天
- 接近底部（约 3 个条目）自动加载更早一页；**每次自动触发必须带来条目增长**，避免无新内容时反复翻页。
- footer 四态：

| 状态 | 文案 | 行为 |
|---|---|---|
| 可加载 | `加载更早` | 可点 |
| 加载中 | `加载更早的记录…` | 不可点 |
| 失败 | `加载失败，点击重试`（Red） | 暂停自动加载，点击重试 |
| 到头 | `已到最早` | 不可点 |

- footer 仅在无 scope 时出现；文本居中 `labelMedium`，水平/垂直 16，整行可点（可点时）。
- 分页窗口中最旧的**未闭合周期**不作为卡片展示，由 footer 承载继续加载，避免半截月/年卡。判定 = `nextCursor != nil` 且窗口最旧日 > 该 group 首日（日历比较）；不能用「group 首日是否有 overview 行」判断，因为无事件日不落行。
- 触底加载失败不自动重试；滚离底部再回来，或上一页成功追加后才重新武装。
- 滚动位置：
  - 从 Gallery / hotSlotView / eventList / AudioGallery 返回时保持原列表位置；
  - 真正切换粒度或下钻时才回到顶部；
  - 浏览与搜索使用各自独立的滚动位置。
- iOS 实现：根首页始终挂载；浏览列表与搜索结果列表各自用独立的 `ScrollViewReader`/视图状态；只有「粒度真的变化」时用顶部锚点滚回 0。

## 4. 搜索模式（UI 部分）

> 搜索数据、topic 聚合、命中跳转细节见 `ios_timeline_topics.md`。

### 4.1 触发与输入

- 搜索框常驻页面顶部：
  - 放大镜 leading（Dust）；
  - placeholder `搜索…` / `Search...`（Dust）；
  - 有文本时 trailing ✕ 清除（`common_clear`）；
  - 单行；文字 14/20（bodyMedium）；Panel 40% 未聚焦 / 60% 聚焦；Line 1pt 边框；Gold 光标；圆角 4（M3 OutlinedTextField 默认）；高 56；水平外边距 16。
- query 非空即进入搜索模式；搜索结果整体替换「选择器 + 浏览列表」区域，选择器隐藏。
- 最少 2 个字符才发起搜索；不足 2 字符显示「至少输入 2 个字」，不发请求。
- 输入 350ms 防抖；键盘搜索键立即发起当前查询。
- 清除按钮、清空文本、顶栏返回（第一次）都会清空 query 并退出搜索模式。
- 点击搜索框外部仅收起键盘、清除焦点，不清空 query。

### 4.2 结果列表

```
共 N 条结果
8月21日
  [💬] 10:24  命中摘要…（最多两行，命中词金色）
  [📄] 09:12  命中摘要…
8月20日
  [🌐] 18:40  命中摘要…
```

- 顶部结果总数（`labelMedium` Dust，水平 16 / 垂直 4）。
- 按命中首次出现的日期分组；组间顺序由检索结果顺序决定，组内保持相关度顺序；日期头为 `M月d日`（不含年份）。
- 行：类型图标 + `HH:mm` + 最多两行 snippet；命中词首次出现处金色高亮（不区分大小写）；无命中不高亮。
- 类型图标（与 Android 一致）：`chat 💬`、`transcribe 📄`、`translate 🌐`、`agent_job 🤖`、`video 🖼️`，未知兜底 `📍`。
- 行内边距：水平 16 / 垂直 8；图标 14/20；时间 `labelMedium` Dust；snippet `bodyMedium` Star。
- 点击任一带 `ts_ms` 的命中行进入 EventList，定位到命中时刻；`ts_ms == nil` 不响应。
- 列表触底自动续页（距末尾 3 个 item）；续页失败保持已有结果，不切错误页。
- 搜索结果不缓存，每次 query 直通 `/search`；新 query 到达即取消上一轮请求。

### 4.3 与浏览状态的关系

- 搜索全局，不受粒度或下钻范围过滤；
- 若存在下钻范围，范围 pill 仍显示在底部，可随时清除；搜索本身不使用该范围；
- 退出搜索后恢复进入前的浏览粒度、范围与滚动位置；
- 从搜索结果进入子页再返回，query 与结果、滚动位置保留；
- 搜索结果与浏览列表使用各自独立的滚动状态；非当前模式的列表 `accessibilityHidden(true)` 且 `allowsHitTesting(false)`，避免 VoiceOver/点击落到隐藏列表。

## 5. 状态与反馈

| 场景 | 页面表现 |
|---|---|
| 首屏数据未就绪 | 列表区域居中「加载中…」；共享窗口已有缓存则直接渲染缓存 |
| 浏览加载失败 | 居中错误文案 + 重试按钮 |
| 无任何记录 | 空态：`还没有记录，开始一次对话吧` |
| 下钻范围无记录 | 空态：`{范围}没有记录` |
| 当前窗口无可见卡片但仍有更早数据 | 不显示空态，显示 footer 继续加载 |
| 触底加载中/失败/到头 | footer 四态 |
| 周期内存在分析中的天 | 卡片顶部脉冲点 +「分析中…」 |
| 搜索不足 2 字符 | `至少输入 2 个字` |
| 搜索请求中 | `搜索中…` |
| 搜索无结果 | `没有找到相关结果` |
| 搜索首屏失败 | 搜索区域错误文案 + 重试 |
| 搜索续页失败 | 保留已有结果，不切错误页 |
| 分析轮询失败 | 保留当前内容，下个周期重试，不打断浏览 |

加载/错误/空态组件的视觉见 `ios_timeline_arch.md` §6.5。

## 6. 数据与刷新

### 6.1 数据来源

首页只使用两个接口：

| 用途 | 接口 | 关键数据 |
|---|---|---|
| 浏览 | `GET /api/mylife/overview` | 设备时区、日摘要、主题、活跃时段、关键帧、分析状态、分页游标 |
| 搜索 | `GET /api/mylife/search` | 命中总数、片段、类型、日期/时刻、分页游标 |

- 首页不直接调用 `/timeline`；该接口只服务于子页。
- overview 只返回有 `day_summary` 行的日期；无事件的日不落行，因此日粒度列表可能跳日（聚合卡的「天数」也按实际日卡数计）。
- 缩略图在 Store 出口转为可直接加载的绝对 URL（附 token）。

### 6.2 窗口与合并

- 首页使用一个由 `MylifeStore` 维护的「已加载窗口」，而不是一次全量；
- 新页按日期去重合并；已加载的更深数据不会被浅页覆盖；
- 每次进入时光机（新 flow）强制拉取第一页，即使 Store 内已有旧快照，避免展示分析完成前的旧摘要；子页返回不清空；
- 响应时区与当前窗口不同时，Store 丢弃旧窗口并按新时区重建；首页同时清除下钻范围；
- 窗口只保存在进程内，不做本地持久化；进程重启后重新拉取。

### 6.3 分析中与自动更新

- Store 在时光机打开期间轮询：已加载窗口最新至多 400 天内只要有任一天 `has_pending`，每 60 秒重取该范围；没有 pending 时停止轮询；
- 更早的深尾不参与自动轮询；
- 轮询与页面生命周期解耦：数据更新后首页自动重聚合，无需手动刷新；
- 轮询失败不改变当前展示，按周期重试。

### 6.4 刷新策略

页面**没有下拉刷新**。内容更新由以下行为驱动：

1. 进入时光机（新 flow）强制拉取第一页；
2. 分析中的 60s 轮询；
3. 列表触底加载更早一页；
4. 浏览/搜索错误态的重试；浏览重试在无 scope 时重取第一页，有 scope 时按 scope 的日范围定位取数（对齐 Android `refresh()` 的 scope 分支）；
5. 图片删除后的延迟窗口刷新（退出 Gallery 时由 Store 执行）；
6. 子页返回时使用根首页保留的窗口与滚动状态。

## 7. 导航与页面状态

| 触发 | 去向 | 携带信息 |
|---|---|---|
| 会话页菜单「时光机」 | 时光机首页 | 无 |
| 首页顶栏返回 | 关闭时光机 | — |
| 首页搜索模式 + 顶栏返回 | 清空 query | — |
| 月卡空白区域 | 页内：日粒度 + 该月范围 | 月 key |
| 年卡空白区域 | 页内：月粒度 + 该年范围 | 年 key |
| 卡片图片/数量角标 | Gallery | from、to、label、focusFrameId、pending |
| 日卡活跃时段 chip | hotSlotView | startMs、endMs、pending |
| 日卡语音入口 | AudioGallery | date、label、count、pending |
| 主题 chip | 页内搜索模式 | search_words 或 topic |
| 搜索命中行 | eventListViewer | tsMs、pending |
| 范围 pill | 页内清除范围 | — |

- 子页以独立栈项压入；首页保留在栈底，返回后保持粒度、范围、query 与滚动位置；
- 关闭时光机后状态销毁；再次进入回到默认日粒度、无范围、空 query，并重新拉取首屏；
- 进程重建后同样回到默认状态；
- 所有子页共享首页传入的「分析中」快照，用于各自顶栏（由子页设计定义）。

## 8. 视觉、时区与本地化

- **视觉空间**：MyLife 子主题（Abyss / 星点 / Gold 标题 / Dust 次要文字 / Panel 半透明卡片 / 12pt 卡片圆角 / 8pt 缩略图圆角）。
- **卡片密度**：图片固定 3 列方格；主题与活跃时段 chip 自动换行，适配窄屏与字体放大。
- **时区**：首页以 overview 响应时区划分「日」；hotSlot/Gallery/Audio 的取数日与 pending 归属按设备时区（Android 既知口径差异）；搜索命中时间按设备本地时间显示。
- **本地化**：当前 17 locale（含 `th`/`vi`，见 `docs/ios_multilingual.md` §2.9）；日期/周/月/年标签、周序号、搜索占位与全部状态文案随 UI locale；数字由系统 locale 输出。
- **Dynamic Type**：所有文本使用 `@ScaledMetric`；chips 自动换行；图片列数不变。
- **Reduce Motion**：脉冲点静态；转场无动画。
- **可访问性**：语音入口合并为单个可读元素（`mylife_audio_entry_desc`）；列表 footer、主题 chip、时段 chip、缩略图均有可读 label；图片数量角标并入图片 label。

## 9. 边界与非目标

**范围内**：入口、宿主头部、搜索 UI、粒度浏览、周期卡片、下钻、分页、页面状态、到子页的导航参数。

**不在范围**：

| 内容 | 参考文档 |
|---|---|
| 图片画廊、查看器与删除 | `ios_timeline_image_gallery.md` |
| 活跃时段查看器 | `ios_timeline_hotslot.md` |
| 语音画廊与播放器 | `ios_timeline_audio_gallery.md` |
| topic 生成、聚合与搜索跳转细节 | `ios_timeline_topics.md` |
| 搜索结果集与 FTS | `docs/bff_search_fts.md` |
| overview/timeline 服务端契约 | `docs/bff_service_interfaces.md` §8 |
| 数据采集、分析管线、摘要生成 | 对应后端/管线文档 |

非目标：

- 不把首页做成事件流或时间线明细列表；
- 不在首页展示原始事件计数、统计徽章、类型过滤条；
- 不提供服务端周/月/年摘要生成，聚合完全在客户端基于日摘要完成；
- 不提供深链、日期定位、底部 tab、横向视图切换；
- 不引入搜索缓存或离线搜索；
- 不实现下拉刷新手势。

## 10. 测试计划

### 10.1 单元

- 粒度分组：日/周（ISO 跨年周）/月/年；分组头月份/年份规则。
- 范围过滤：月/年 scope、空 scope、非法 key。
- 卡片：summary 全部/4/5/6 条与 2 行折叠、「+N」；无摘要降级「范围 + N 天」；日卡无折叠。
- 图片轮转：windowId 为空回退 eventRef、cap 3/9/12/15、同 ts 稳定、跨日同窗。
- 主题：日卡全量；≤50 原序；>50 权重优先且稳定。
- 音频入口：仅日卡、count>0。
- 未闭合周期过滤；footer 四态；scope 内无 footer。
- 搜索 UI 状态：Idle/Loading/Empty/Error/Data；350ms；<2 字符；清空退出。
- 日期标签 en/zh：日/周/月/年/分组头/搜索日头。

### 10.2 UI

- 入口打开/关闭；菜单无配置时进设置。
- 默认日粒度；切周/月/年；月/年下钻；scope pill 清除；切换粒度清 scope。
- 卡片内容顺序；图片角标；主题/时段/语音入口点击分别导航。
- footer 四态；触底加载；失败后不自动重试。
- 搜索输入/防抖/不足 2 字/无结果/结果分组/高亮/点击命中；返回清 query。
- 返回子页后滚动与搜索状态保持。
- 大字号/Reduce Motion 冒烟。

### 10.3 真机

- 真实 server 的 overview 分页、pending 轮询、时区切换。
- 自签 TLS 下图卡加载。
- iPad 兼容模式 600pt。
