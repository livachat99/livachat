# LivaChat

LivaChat is an open-source, real-time multimodal AI companion platform. It includes:

- **A complete real-time AI chat server** — low-latency duplex voice and text conversation, live transcription, and live translation.
- **An AI data-analysis server** — turns everyday conversations plus audio/video data into structured, searchable information, presented as a time-machine-style timeline.
- **Ready-to-use mobile apps** — native Android and iOS clients built on the same open-source stack.

## Features

- **Real-time AI chat** over voice and text, with interruptible turns and low-latency Opus audio.
- **Live translation and live transcription** for 60+ languages.
- **Omni-modal conversation** — audio and vision handled in one model.
- **Agent integration** — connect Hermes or OpenClaw agents and drive long-running tasks by voice or chat: news analysis, daily finance reports, research, and more.
- **A time machine for your data** — daily conversations and audio/video recordings are analyzed by AI and turned into valuable, browsable memories.
- **Fully open source** — server and app source code are both available.

## Server installation

Prerequisites: macOS or Linux with `ffmpeg` and `libopus`,  windows can use wsl2. 

Install them with your platform's package manager:

```bash
# macOS (Homebrew)
brew install ffmpeg opus

# Ubuntu / Debian
sudo apt update && sudo apt install -y ffmpeg libopus0

# Fedora
sudo dnf install -y ffmpeg-free opus

# Arch Linux
sudo pacman -S --needed ffmpeg opus
```

Then install and start the server:

```bash
git clone <REPOSITORY_URL>
cd <REPO_DIR>
./livachat.sh install
cp .env.example .env
# Edit .env and fill in the required fields (DashScope API key, API host, workspace ID, app auth token)
./livachat.sh start
./livachat.sh status   # check that the servers are running
```


## Mobile apps

### Build from source

- **Android** — requires Android Studio / the Android SDK:
  ```bash
  cd apps/android
  ./gradlew :LivaChatApp:installDebug
  ```
- **iOS** — requires Xcode:
  ```bash
  open apps/ios/LivaChatApp/LivaChatApp.xcodeproj
  ```
  Select the `LivaChatApp` scheme, then build and run on a device or simulator.

## Agent connections

LivaChat supports Hermes and OpenClaw agents for long-running tasks. You can chat with LivaChat in real time while Hermes or OpenClaw handles long-running tasks.

### Hermes

1. Set `HERMES_DASHBOARD_SESSION_TOKEN` in `~/.hermes/.env`, for example:
   ```bash
   HERMES_DASHBOARD_SESSION_TOKEN=1f24c4b057d3bacaee4b759ce8441e8e
   ```
2. Start the Hermes server instance:
   ```bash
   nohup hermes serve &
   ```
   The LivaChat server will connect to Hermes at `http://localhost:9119`.
3. Put the same token into the LivaChat repo-root `.env` as `HERMES_AUTH_TOKEN`, for example:
   ```bash
   HERMES_AUTH_TOKEN=1f24c4b057d3bacaee4b759ce8441e8e
   ```
4. Restart the LivaChat servers for the change to take effect:
   ```bash
   ./livachat.sh stop
   ./livachat.sh start
   ```

   See `configs/test/server.yaml` (generated by `./livachat.sh install`) for details.

### OpenClaw

1. Get `gateway.auth.token` in `~/.openclaw/openclaw.json` (OpenClaw generates it automatically), for example:
   ```json
   {
     "gateway": {
       "auth": {
         "token": "14f41e189dd9f81c4f0d91d135f76cd3"
       }
     }
   }
   ```
   The LivaChat server will connect to OpenClaw at `ws://127.0.0.1:18789`.
2. Put the same token into the LivaChat repo-root `.env` as `OPENCLAW_AUTH_TOKEN`, for example:
   ```bash
   OPENCLAW_AUTH_TOKEN=14f41e189dd9f81c4f0d91d135f76cd3
   ```
3. Restart the LivaChat servers for the change to take effect:
   ```bash
   ./livachat.sh stop
   ./livachat.sh start
   ```

   See `configs/test/server.yaml` (generated by `./livachat.sh install`) for details; add `openclaw` to `agent_relay.default_adapters` to enable it.
